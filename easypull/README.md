# EasyPull

Draws dotted circles in world space around your player or current target.

Useful for marking pull ranges, collat zones, bla bla. You get the idea.

![EasyPull menu and examples](https://i.imgur.com/lgluR63.png)

## Usage

- Click the **EasyPull** button to open the menu.
- **+ Circle** adds another circle.
- **-** removes a circle.
- **Player / Target** switches what the circle follows.
- **-R / +R** changes that circle's radius.
- **Offset** selects a circle for editing.
- Arrow buttons move the selected circle forward/back/left/right.
- **- Dots / + Dots** changes dot density for the selected circle.
- Color buttons change the selected circle's color.

Player circles move with you. Target circles move with your current target.
